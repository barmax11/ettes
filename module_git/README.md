Module Git

Опис проєкту

Навчальний Python-проєкт для роботи з Git та вивчення структури програм.

Структура проєкту

src/ — основний програмний код.

tests/ — автоматизовані тести.

books/ — дані про книги.

config/ — налаштування проєкту.

main.py — головний файл програми.

command.sh — команди термінала.
